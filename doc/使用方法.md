# 使用方法（TLDR）

无信号灯人行横道的人车冲突风险预警原型：读取 CCTV 风格视频，用 YOLO11s + ByteTrack 检测跟踪行人与车辆，按手工标定的 ROI 计算 0–100 风险分，输出可视化/日志/语音成片。细节见 [README.md](../README.md)。

## 1. 环境（首选 uv）

- 安装 [uv](https://docs.astral.sh/uv/)；需要 Python 3.14+（`.python-version` 已固定为 3.14，uv 会自动下载）
- 安装依赖：

```bash
uv sync
```

`uv.lock` 已锁定全部版本，`pyproject.toml` 里配置了 PyTorch cu126 国内镜像源，`uv sync` 会装到 GPU 版 torch。

- 权重 `yolo11s.pt` 放在项目根目录；缺失时 ultralytics 会联网自动下载

> 没有 uv 时的备选：`pip install -r requirements.txt`。注意 `requirements.txt` 不含 torch，且没有镜像源配置，需自行确保装的是需要的 torch 版本。

## 2. 跑通 demo（最常用）

```bash
uv run python main.py --config config/config.yaml
```

一条命令依次完成：检测 → 跟踪 → ROI 风险评分 → 可视化叠加 → 事件/帧日志 → 语音告警 → H.264 成片 → 风险曲线 → 代表截图。

| 场景 | 命令 |
|---|---|
| 只跑 CV，不出语音和 H.264 | `uv run python main.py --skip-audio` |
| 切换界面语言（默认 `zh_cn`） | `uv run python main.py --lang en_us` |

## 3. 输出文件

| 内容 | 路径 |
|---|---|
| 带语音的成片 | `outputs/videos/output_crosswalk_risk_yolo11s_60s_with_voice_h264.mp4` |
| 合成语音 | `outputs/videos/warning_audio_voice.wav` |
| 事件日志（HIGH/DANGER） | `outputs/logs/event_log_crosswalk_yolo11s_60s.csv` |
| 帧日志（约每秒一条） | `outputs/logs/frame_log_crosswalk_yolo11s_60s.csv` |
| 风险曲线 / 代表截图 | `assets/results/` |

## 4. 摄像头实时模式

同一个 pipeline，只是换成摄像头输入。**必须先用摄像头自己的画面标定 ROI**（视频帧尺寸不同会被 pipeline 直接拒绝）。

**方式 A：现场标定（推荐，任意相机/机位）**

```bash
uv run python tools/calibrate_roi.py --source 0
```

`1`–`5` 切换要画的区域（人行道 / 车辆接近区 / 行人等待区 / 次要人行道 / 次要接近区），左键加点、右键或 `u` 撤销、`c` 清当前区域、`x` 全清、`H` 采集俯视图四角点、`s` 校验并保存。

**方式 B：摄像头对着屏幕播 demo 视频时，复用已有标定**

```bash
uv run python tools/make_webcam_roi.py --source 0 --interactive
```

框选屏幕中视频所在区域后按 ENTER/SPACE，确认 ROI 落在人行道上，再按 `s` 保存到 `config/webcam_roi.json`。

**运行**

```bash
uv run python run_webcam.py --roi-config config/webcam_roi.json --source 0
```

- 加 `--save` 保存输出视频
- 预览窗口按 `q` 退出
- `--source` 也可是视频文件或 RTSP 地址；用 demo 视频时改配 `--roi-config config/crosswalk_roi.json`

## 5. 风险等级速查

| 分数 | 等级 | 表现 |
|---|---|---|
| 0–24 | LOW | 无叠加 |
| 25–49 | MEDIUM | 黄色叠加 + 帧日志 |
| 50–74 | HIGH | 橙色叠加 + 语音 "Caution. Pedestrian crossing." |
| 75–100 | DANGER | 红色叠加 + 语音 "Warning. Vehicle approaching. Please stop." |

## 6. 常见坑

- ROI 文件自带 `frame_width`/`frame_height`，与输入帧尺寸不符时 pipeline 会拒绝运行——这是设计行为，不是 bug。
- `config/crosswalk_roi.json` 是为 `data/demo/crosswalk_best_60s.mp4`（1200×1100）标定的，换相机不能直接用。
- `config/webcam_roi.json` 与相机、机位绑定，未纳入版本管理，换设备请重新生成。
- 风险分是图像空间启发式指标，TTC 也是图像空间近似，**不是**真实米制速度/距离。
- `outputs/` 和 `assets/results/` 下的图片已被 `.gitignore` 忽略。
- 语音告警是后期合成进成片的，未连接真实音箱、行车记录仪或 V2X 设备。
